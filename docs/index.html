🦊 Fenek German

Fenek German publishes short German lessons for English speakers: everyday vocabulary with der/die/das, real-life dialogues, quizzes and word searches, all explained in English.

This site describes the publishing tool behind the Fenek German YouTube channel. The tool renders our own original animations and uploads them to our own channel using the YouTube Data API. It does not access any other user's data.
